# VS‑Code‑Default Theme for Xed‑Editor

VS‑Code‑Default brings the look of VS Code’s built‑in Dark+ and Light+ default themes to Xed‑Editor.
This theme reproduces the well‑known syntax colors you are familiar with from Visual Studio Code.

Both light and dark variants are included. It works with automatic system dark‑light switching.

All editor elements are fully styled: code syntax highlighting, line numbers, current‑line highlight, code completion pop‑ups, error and warning hints, as well as the built‑in terminal.

## Features
- Faithful recreation of VS Code Dark+ (dark) and Light+ (light) color scheme
- Complete syntax highlighting for most programming languages
- Matching color palette for Xed built‑in terminal
- Adjusted UI components: selection, scrollbars, inlay hints, diagnostic tooltips
- Support system automatic light‑dark switch
